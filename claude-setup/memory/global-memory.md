## サイト制作（LP・Webページ）の進め方

LP、ホームページ、店舗やサービスのWebページ、バナー、Webのアニメーションに関わる依頼を受けたら、次に従う。

### 使うスキル（~/.claude/skills/ に導入済み）
- **lp-maker**：LPを1ページ作る社内手順。LPやサイト1ページの依頼では最初にこれを使う。
- **ui-ux-pro-max**：配色・フォント・デザインスタイルを決めるときに使う。コードを書く前に決め、選んだ理由を一言添える。
- **motion-design**：アニメーションや動きを付けるときに使う。控えめにして、読みやすさを優先する。
- スキルが見つからない場合は、`h2t.syuhou` リポジトリの `claude-setup/README.md` の手順で入れ直すよう案内する。

### 決まりごと（ユーザーの希望）
- 日本語フォントはメイリオを基本にする（見出しだけ、無料の Google Fonts の明朝体などを使ってよい）。
- スマホ表示を優先し、HTML1ファイルで出力する。
- AIっぽい、ありきたりな配色や文字は避ける（紫〜青のグラデーション、汎用のコピー、絵文字のアイコンなど）。
- 無料で使える素材とライブラリだけを使う。有料プランの契約、課金、APIキーの登録が必要な手順は実行せず、そこで止めて報告する。
- 参考サイトがあれば構成と雰囲気だけを寄せ、文章と画像はそのまま流用しない。
- 完成したらブラウザで開いて崩れを確認し、直してから報告する。
- 店名・住所・電話・価格・予約URLが分からないときは仮の値で作り、差し替えが必要な箇所を一覧で報告する。
- 依頼文のひな形は `~/.claude/skills/lp-maker/lp-request.md`。【例：…】のまま届いた欄は例の内容で作り、そのことを伝える。

### 報告のしかた
- 日本語で、専門用語を避けて分かりやすく書く。
- 入った場所や使い方を聞かれたら、短く（3行程度ずつ）まとめる。
- うまくいかないときは、原因と、ユーザーが手で打つべきコマンドを示す。
